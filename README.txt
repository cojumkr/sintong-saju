신통사주 v5.1 관리자 주간 예약표 오류 수정

1. index.html을 GitHub 저장소 최상위에 업로드하고 기존 파일과 교체하세요.
2. Firestore 규칙은 기존 v5와 동일합니다. 이미 게시했다면 다시 게시할 필요가 없습니다.
3. 브라우저 새로고침(Ctrl+Shift+R) 후 관리자 로그인을 시험하세요.
4. 관리자 계정은 Firebase Authentication 및 Firestore admins/{UID} enabled=true가 필요합니다.
5. 가상 예약으로 두 기기 테스트 전까지 실제 예약 접수는 보류하세요.

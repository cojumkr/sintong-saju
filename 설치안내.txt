신통사주 v5 - Firebase 실시간 예약 연동

0. 기존 v4의 브라우저에 저장된 영업시간과 예약은 자동 이전되지 않습니다. 관리자에서 새로 입력하세요.
1. Firebase Authentication > Sign-in method: Anonymous 및 Email/Password 활성화.
2. Firebase Authentication > Users > Add user:
   Email = [관리자 전화번호 숫자 11자리]@admin.sintong-saju.app
   Password = 6자리 이상 강력한 비밀번호 (8888은 사용할 수 없습니다).
3. 위 User의 UID를 복사합니다.
4. Firestore Database > 데이터 > 컬렉션 시작: admins
   문서 ID = 위 UID, 필드 이름 enabled, 유형 boolean, 값 true.
   해당 문서는 콘솔에서 생성합니다. 사이트에서는 관리자 문서를 만들 수 없습니다.
5. Firestore Database > Rules에서 첨부 firestore.rules의 전체 내용을 복사하고 Publish.
6. GitHub > cojumkr/sintong-saju 저장소의 index.html을 첨부 index.html로 교체하고 Commit changes.
7. 사이트를 열고 관리자로 로그인해 날짜별 영업시간을 새로 지정한 다음,
   서로 다른 두 기기에서 가상 예약을 시험하고 두 번째 기기에 해당 시간이 잠기는지 확인하세요.

주의
* 로그인 화면에는 전화번호만 표시되지만 Firebase 내부에서는 이메일/비밀번호 인증을 사용합니다.
* 관리자 화면은 앱을 다른 화면으로 전환하면 로그아웃하도록 구현했습니다.
* 고객은 익명 로그인합니다. 예약조회의 이름+번호 확인은 같은 익명 UID(브라우저)에서만 가능합니다.
  다른 휴대폰에서 이름+번호만으로 열람하는 기능은 개인정보 보호상 의도적으로 제공하지 않았습니다.
* 익명 예약은 SMS 인증이 없어 가짜 번호와 반복 신청을 완전히 막을 수 없습니다.
  신규 예약에 대한 악용 방지 및 운영 검증이 필요합니다.
* 보안 규칙은 코드 검토용입니다. Firebase 실제 환경의 통합 테스트 전 고객 실정보 입력을 권장하지 않습니다.
* 업로드 후 사이트나 오류에 문제가 있다면 Firestore 규칙의 게시 여부, admins/UID 문서,
  Email/Password/Anonymous 활성화 및 브라우저 개발자 콘솔을 확인하십시오.
